# Itération 4 - Infrastructure de messagerie

Cette itération prépare l'architecture d'une messagerie interne basée sur
Postfix, Dovecot et Roundcube.

## Objectif

Identifier les services nécessaires, leurs responsabilités et les échanges
entre eux avant toute installation.
