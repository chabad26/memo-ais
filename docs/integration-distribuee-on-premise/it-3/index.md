# Itération 3 - Authentification centralisée et partage

Cette itération étudie la transformation de l'annuaire de laboratoire en
service d'authentification centralisée et de partage de fichiers.

Les activités abordent Samba Active Directory, Kerberos, DNS, LDAP et SMB
avant les déploiements techniques.

Le rôle du `Dockerfile`, du Compose, de `entrypoint.sh` et des configurations
Samba est détaillé dans le
[guide des fichiers techniques](../comprendre-fichiers-techniques.md#samba-et-openldap).
