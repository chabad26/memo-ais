# Glossaire Administration Windows — Activité 12

## Sujet

Dossier d'exploitation de l'infrastructure Windows construite pendant les activités 1 à 11.

## Éléments à retenir

| Élément | Contenu attendu |
| --- | --- |
| Architecture | Machines, rôles, domaine, adressage et dépendances. |
| Active Directory | OU, comptes, groupes et organisation des accès. |
| Sécurité | GPO, BitLocker, Windows LAPS et pare-feu. |
| Fichiers | `SRV-FIC01`, partages SMB, droits NTFS et modèle AGDLP. |
| Continuité | Shadow Copies, sauvegarde, restauration et reprise d'exploitation. |
| Automatisation | Scripts PowerShell, inventaires et rapports produits. |
| Preuves | Captures contextualisées, résultats de commandes et tests reproductibles. |

!!! warning "Sécurité documentaire"
    Ne jamais publier de mot de passe, secret LAPS, clé BitLocker, mot de passe DSRM ou autre donnée sensible dans un livrable.

## Réflexes opérationnels

- dater et versionner le document ;
- distinguer les faits vérifiés des points restant à traiter ;
- documenter les procédures de contrôle et de reprise ;
- fournir suffisamment de contexte pour qu'un tiers puisse reprendre l'exploitation.
