# Droit et conformité — Itération 1

## Termes à retenir

| Terme | Sens |
| --- | --- |
| GRC | Gouvernance, risques, conformité : décider, traiter les risques, démontrer le respect des exigences |
| Applicabilité | Justification du lien entre le champ d'un texte et les faits de l'organisation |
| Réglementation | Exigences juridiques dans un champ défini |
| Norme | Référentiel généralement volontaire, pouvant être exigé par contrat |
| Exigence contractuelle | Engagement accepté dans un contrat |
| PSSI | Politique interne de sécurité, à approuver et à appliquer |
| NIS2 | Directive européenne : champ, qualification, gestion des risques et incidents |
| EE / EI | Entité essentielle / importante ; qualification à argumenter |
| OSE | Opérateur de services essentiels sous NIS1 ; terme distinct de EE sous NIS2 |
| Matrice d’applicabilité | Relie source, exigence, applicabilité, contrôle, preuve, état, écart et action |
| Traçabilité | Producteur, date, origine, périmètre, méthode et conservation d’une preuve |
| OIV | Opérateur d'importance vitale désigné dans le cadre français ; statut non prouvé pour ÉnergieAlp |
| ReCyF | Référentiel Cyber France ; vérifier la version et le statut avant de l'utiliser |
| Cloud Act | Cadre américain d'accès légal aux données ; analyser la juridiction et le contrôle des données |
| Preuve | Élément daté qui étaye une conclusion dans un périmètre explicite |

## Gestes à retenir

1. Lire le champ d'application avant de lister les obligations.
2. Relier chaque conclusion à un fait du dossier et à un article.
3. Distinguer directive, droit français applicable, recommandation et contrat.
4. Conserver sources, dates, exclusions justifiées et informations manquantes.
5. Utiliser le simulateur comme aide à la préqualification, puis argumenter.
6. Planifier les remédiations selon la disponibilité, les fenêtres et les responsables du dossier.

7. Distinguer applicabilité partielle et conformité partielle.
8. Relier les preuves par identifiant et documenter leurs limites.

## Manipulations faites

Aucune utilisation du simulateur, aucun audit réel et aucune remédiation ne sont documentés à ce stade.
