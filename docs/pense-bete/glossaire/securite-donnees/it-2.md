# Glossaire Sécurité des données - Itération 2

| Terme | Définition courte |
| --- | --- |
| TLS | Protocole qui protège une communication réseau par chiffrement et authentification. |
| Certificat X.509 | Format de certificat contenant identité, clé publique et signature. |
| Autorité de certification | Autorité qui émet et signe des certificats. |
| Chaîne de confiance | Suite de certificats reliant un certificat à une racine approuvée. |
| Clé privée | Clé secrète qui doit rester protégée par son propriétaire. |
| Négociation TLS | Échange initial qui choisit les paramètres et établit les secrets de session. |
| Suite cryptographique | Ensemble d'algorithmes utilisés par une connexion TLS. |
| SNI | Indication du nom de service présentée au début d'une connexion TLS. |
