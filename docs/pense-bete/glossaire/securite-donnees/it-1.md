# Glossaire Sécurité des données - Itération 1

| Terme | Définition courte |
| --- | --- |
| Confidentialité | Empêcher la lecture par une personne non autorisée. |
| Intégrité | Garantir qu'une donnée n'a pas été modifiée. |
| Authenticité | Vérifier l'identité d'un émetteur ou l'origine d'une donnée. |
| Chiffrement symétrique | Chiffrement et déchiffrement avec une même clé secrète. |
| Chiffrement asymétrique | Utilisation d'une clé publique et d'une clé privée associée. |
| Fonction de hachage | Transformation à sens unique produisant une empreinte. |
| MAC | Code d'authentification calculé avec un secret partagé. |
| Signature numérique | Preuve d'origine et d'intégrité produite avec une clé privée. |
| Certificat | Association signée entre une identité et une clé publique. |
