# Référentiel cryptographique ANSSI - Synthèse

Cette ressource transversale accompagne les activités du module **Sécurité des
données**. Elle synthétise les règles et recommandations du guide
`ANSSI-PG-083`, version 3.00.

## Tableau récapitulatif

[Ouvrir ou télécharger la synthèse ANSSI au format PDF](ANSSI_Regles_Recommandations_Cryptographiques_3.00.pdf)

Le document présente notamment :

- les règles classiques nécessaires à la conformité ;
- les recommandations qui ajoutent une marge de sécurité ;
- les règles et recommandations post-quantiques ;
- des exemples de mécanismes conformes ou non conformes ;
- les tailles et paramètres cryptographiques à vérifier.

| Mention | Signification |
| --- | --- |
| `Règle` | Condition nécessaire pour déclarer un mécanisme conforme au référentiel. |
| `Reco` | Condition supplémentaire correspondant à l'état de l'art et à une marge de sécurité accrue. |
| `RèglePQ` | Condition nécessaire lorsqu'une résistance aux attaques quantiques est recherchée. |
| `RecoPQ` | Marge de sécurité supplémentaire pour un objectif post-quantique. |
| Conforme | Le mécanisme respecte les règles applicables dans le contexte étudié. |
| Non conforme | Au moins une règle applicable n'est pas respectée. |
| Non vérifiable | Les informations disponibles ne suffisent pas pour conclure. |

!!! warning "Synthèse pédagogique"
    Ce PDF facilite le repérage des recommandations, mais ne remplace pas le
    texte complet du guide ANSSI. Une conclusion de conformité doit tenir
    compte du contexte, des paramètres exacts et des limites précisées dans le
    référentiel officiel.
