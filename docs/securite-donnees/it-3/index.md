# Itération 3 - Données au repos et LUKS

## Objectif

Mettre en œuvre un stockage Linux chiffré avec LUKS, en utilisant un fichier et
un périphérique loop pour simuler un support de stockage.

## Feuille de l'itération

- créer et initialiser un volume LUKS ;
- ouvrir, monter, utiliser puis fermer le volume ;
- vérifier que les données sont protégées au repos ;
- identifier le header et les moyens nécessaires à l'ouverture.

## Livrable attendu

Un stockage LUKS opérationnel, reproductible et accompagné d'une documentation
minimale de vérification.
