# Itération 2 - Données en transit et TLS

## Objectif

Comprendre l'établissement d'une connexion TLS, le rôle des certificats, des
clés et des autorités de certification, puis vérifier une configuration et sa
chaîne de confiance.

## Feuille de l'itération

- observer la négociation TLS ;
- vérifier un certificat, son émetteur, sa période de validité et son usage ;
- analyser les paramètres importants d'une configuration TLS ;
- documenter les écarts et les corrections proposées.
